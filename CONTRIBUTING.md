# Contributing to bisibility for DeepSeek Harness

Thank you for helping improve the plugin.

## Where to File What

- Bug reports and problems with installing or updating the plugin: use the issue
  tracker here. Include your DeepSeek Harness version, the plugin version, and what the
  panel or startup reported.
- Feature ideas and anything product-wide: use the
  [bisibility hub](https://github.com/CorgiCorner/bisibility).

## Pull Requests

This repository is published from releases, and pull requests are turned off. If you
have a fix, describe it in an issue, with a patch or a snippet if that helps; the
maintainers apply it and credit you in the release notes.

Keep credentials, tokens, and personal data out of issues, logs, and screenshots.
